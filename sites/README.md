## 规范

- **原语自包含**:每个脚本自己 `cdp.resolve(url/title 子串)` 定位 target,不假设"当前选中页";用 `cdp` 全局 + 白名单 `require`。用绝对路径 `cdp.js run sites/<域名>/<原语>.js` 执行。
- **头部注释模板**(每个原语必带),见 [_template/primitive.js](_template/primitive.js):
  - `站点 / 用途 / 用法 / 返回结构 / 依赖的 DOM 结构假设 / 最后验证日期 / 状态`
- **生命周期**:
  - 实测验证通过 → 更新头部"最后验证 / 状态"。
  - 站点改版失效 → **更新或删除原语**,并在该站 README 标记失效现象。
  - 每站 README 维护"可用 / 失效"清单,供新任务先导航。
- **新任务流程**:用到某站 → 先看该站 README + 目录里现成原语 → 能复用直接 `run`;缺什么就写新的并升格进目录(验证通过后)。

## 新建一个站点

1. 复制 `_template/` → `sites/<域名>/`,或直接建目录。
2. 写 `README.md`(站点导航)+ 一个或多个单用途原语。
3. 回本文件加一行总索引。

## 目录约定

- 目录名 = 域名主体(如 `zhihu`、`clsl`);同域多个子站(如 z.cn/zhihu.com)归一到一个目录。
- 每个原语**一个脚本文件、只干一件事**。多步流程由任务脚本在项目根按需组合调用这些原语(或直接 run 单个原语)。
